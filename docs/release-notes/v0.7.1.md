# BabelDOC v0.7.1

## Bug Fixes

- Fixed a regression in 0.7.0 where constructing `TranslationConfig` without an `input_file` (for example, a configuration used only to drive a progress display) raised `TypeError`. This broke the `pdf2zh_next` command line with BabelDOC 0.7.0.\
  修复 0.7.0 引入的回归：不传 `input_file` 构造 `TranslationConfig`（例如只用于驱动进度显示的配置）时会抛出 `TypeError`，导致 `pdf2zh_next` 命令行在 BabelDOC 0.7.0 下无法使用。
